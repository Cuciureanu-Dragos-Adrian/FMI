program 
program de incalzire zilnic:

-- partea de incalzire:
incalzirea fiecarei parti contodente
-> rotirea gatului: 15 sec
-> aplecarea capului lat si fata/spate: 15 sec
-> bratele pe solduri si rotirea umerilor fata spate: 2 set a cate 8
-> rotiri de brate fata/spate/alternativ: 2 set a cate 8
-> rotirea antebratelor 2 set a cate 8 (unu in ext unu in int)
-> rotirea bazinului: 15 sec
-> aplecarea trunchiului cu extensia bratelor opuse: 2 set a cate 8
-> morisca 20 sec
-> fandari cu schimbare prin saritura:
-> incalzirea incheieturilor la maini si picioare

-- partea fundamentala:
axati mai mult pe abdomen pt spatiul casei
-> pt triceps flotari la pat/scaun
-> plank 1 min
-> plank cu ridicare
-> flotari cu mainile departate pt antrenarea triceps-ului
-> flotari cu gantere
-> abdomene normale 2 serii de 15
-> abdomene cu ridicari pana la genunchi
-> prindem genunchii de jos 8 sec/picior
-> prindem genunchi cu mainile cu laba piciorului ridicata 5 sec/picior

-- partea de streching:
-> lasarea pe spate -> lasarea in fata -> lebada 10 sec/pozitie
-> pt mobilitate: atingem varful picioarelor
